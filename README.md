# Peri & Calm — Instagram media

Public image and video assets for the Instagram account **@periandcalm**, used as media links for scheduling posts, Reels and Stories.

- `posts/` — carousel slides (one folder per post)
- `reels/` — short faceless videos
- `stories/` — Story images

This repository contains **social media assets only**. Paid products (guides, trackers, PDFs or any other downloadable product files) are never stored here.

Wellness content — not medical advice.
